# mobile

Client mobile, développé après le client web. Mêmes responsabilités que `apps/web`, avec en plus la gestion de la mise en arrière-plan de l'app et des reconnexions.

## Dépendances autorisées

- `packages/rules`
- `packages/protocol`

Aucune dépendance vers `apps/server` ni `apps/web`.
